# Retail Project SQL

Pre-entrega del curso de SQL de Coderhouse.

## Cómo ejecutarlo
1. Crear una base de datos llamada `retail_project` en PostgreSQL.
2. Abrir pgAdmin o DBeaver y conectarse a esa base.
3. Abrir el archivo `script.sql` y ejecutarlo completo.

## Contenido
- Creación de las tablas clientes, productos y ventas con restricciones (PRIMARY KEY, FOREIGN KEY, UNIQUE, NOT NULL y CHECK).
- Carga inicial de 5 registros por tabla dentro de una transacción (BEGIN ... COMMIT).
- UPDATE de precios por categoría y DELETE de una venta, ambos con WHERE.
